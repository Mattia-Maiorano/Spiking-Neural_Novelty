# Release Notes: SPWM-v6.5 (Kinematic Unlocking & Momentum-Velocity Consistency)

## Overview
**SPWM-v6.5** addresses the "kinetic blindness" phenomenon observed in previous iterations (v6.3 and v6.4), where the predictive world model achieved fine spatial tracking on coordinate positions ($q \in \mathbb{R}^{32}$, reaching `val_pos_err` $\approx 0.072$) but suffered from velocity probe stagnation (`val_vel_err` $\approx 0.65$).

This release introduces an explicit **Kinematic Velocity Consistency Loss** ($\mathcal{L}_{\text{vel\_cons}}$) with coupling weight $\lambda_{\text{vel\_cons}} = 0.25$, enforcing Hamiltonian consistency between the canonical momentum subspace $p \in \mathbb{R}^{96}$ and the empirical temporal variation of coordinates $\Delta q = q_{t+1} - q_t$.

---

## Key Architectural Highlights

### 1. Velocity Consistency Loss ($\mathcal{L}_{\text{vel\_cons}}$)
- **Operator**: $W_{\text{vel\_cons}}: \mathbb{R}^{p_{\text{dim}}} \to \mathbb{R}^{q_{\text{dim}}}$ (linear mapping initialized with orthogonal weights).
- **Formulation**:
  $$\mathcal{L}_{\text{vel\_cons}} = \frac{1}{T-1} \sum_{t=0}^{T-2} \left\| W_{\text{vel\_cons}} p_t - (q_{t+1} - q_t) \right\|_2^2$$
- **Target Subspace**: Momentum $p$ (generated by the 256-neuron ALIF dual-timescale memory population).
- **Weight**: $\lambda_{\text{vel\_cons}} = 0.25$.

### 2. Full Composite Loss Specification
$$\mathcal{L}_{\text{total}} = \lambda_{\text{pred}} \mathcal{L}_{\text{pred}} + \lambda_{\text{multi}} \mathcal{L}_{\text{multi}} + \lambda_{\text{var}} \mathcal{L}_{\text{var}} + \lambda_{\text{sparse}} \mathcal{L}_{\text{sparse}} + \lambda_{\text{probe}} \mathcal{L}_{\text{probe}} + \lambda_{\text{coord}} \mathcal{L}_{\text{coord}} + \lambda_{\text{vel\_cons}} \mathcal{L}_{\text{vel\_cons}}$$

| Term | Symbol | Weight ($\lambda$) | Purpose |
|---|---|---|---|
| One-Step Latent Prediction | $\mathcal{L}_{\text{pred}}$ | 1.0 | Local Teacher-Forced 1-step transition |
| Multi-Step Autoregressive | $\mathcal{L}_{\text{multi}}$ | 0.5 | Horizon $K \in \{3, 6, 10\}$ exposure bias mitigation |
| Anti-Collapse Variance | $\mathcal{L}_{\text{var}}$ | 0.1 | Feature standard deviation preservation |
| Spike Sparsity Lock | $\mathcal{L}_{\text{sparse}}$ | 0.0025 | ALIF firing rate homeostatic corridor (10%-12%) |
| Diagnostic Kinematic Probe | $\mathcal{L}_{\text{probe}}$ | 2.0 | Physical decoder alignment |
| Spatial Coordinate Anchor | $\mathcal{L}_{\text{coord}}$ | 0.15 | SpatialSoftmax keypoint geometric anchoring |
| **Kinematic Velocity Consistency** | $\mathcal{L}_{\text{vel\_cons}}$ | **0.25** | **Momentum-to-velocity Hamiltonian grounding** |

---

## Configuration & Hyperparameters (v6.5)
- **Model**: `SPWM` (256 ALIF units, dual timescale `[128, 128]` with $\beta = [0.90, 0.985]$).
- **Latent Partitioning**: $z \in \mathbb{R}^{128}$ decomposed into $q \in \mathbb{R}^{32}$ and $p \in \mathbb{R}^{96}$.
- **Curriculum Thresholds**:
  - Phase 1: $K=3$ for `val_pos_err` $\ge 0.20$
  - Phase 2: $K=6$ for `val_pos_err` $< 0.20$
  - Phase 3: $K=10$ for `val_pos_err` $< 0.12$
- **Training Budget**: 450 epochs, learning rate $2 \times 10^{-4}$, probe learning rate $5 \times 10^{-4}$.
